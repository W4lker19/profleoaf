Configuração inicial

Faz-se só uma vez. Colas o token do GitHub e escolhes uma palavra-passe. O token fica guardado no repositório, cifrado com essa palavra-passe, e a partir daí basta a palavra-passe para entrar em qualquer browser.

Como criar o token
  1. No GitHub: Settings da conta › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Validade: até ao fim do ano letivo.
  3. Repository access: Only select repositories › profleoaf.
  4. Permissions › Repository permissions › Contents: Read and write. Mais nenhuma.
  5. Generate token e copiar logo (só é mostrado uma vez).

Usa pelo menos 12 caracteres. Uma frase com quatro ou mais palavras ao acaso funciona bem e é fácil de lembrar.

Atividades

Depois de guardar, o site atualiza em um ou dois minutos. As atividades agendadas abrem sozinhas na data escolhida, sem precisares de voltar aqui.
