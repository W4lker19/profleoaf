LimparBrowsers — instalador para os PCs da sala

Depois de descarregar

  1. Abra o ficheiro Instalar LimparBrowsers.exe (em Transferências).
  2. Se o Edge disser que o ficheiro não é transferido normalmente, escolha Manter.
  3. Se aparecer "O Windows protegeu o seu PC", carregue em Mais informações e depois em Executar mesmo assim.
  4. No menu, carregue em Enter para instalar. No fim, o instalador apaga-se sozinho das Transferências.
